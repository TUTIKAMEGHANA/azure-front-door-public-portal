# Azure Evidence Screenshots

Create these folders and place the **real screenshots from your team's Azure environment** inside them.

```text
screenshots/
├── task-1/
├── task-2/
├── task-3/
├── task-4/
└── task-5/
```

## Required Evidence

### Task 1
- Resource Group creation/review
- Resource Group overview

### Task 2
- Hosting resource overview
- Public portal running
- Portal/static resources

### Task 3
- Front Door profile
- Origin/origin group
- Endpoint/route
- Cache configuration
- Front Door endpoint

### Task 4
- WAF policy
- Security rules
- WAF association
- WAF log/security event

### Task 5
- Custom domain
- DNS validation
- HTTPS/TLS
- Browser showing HTTPS domain
- Final testing evidence

**Do not use generated or edited screenshots as proof of execution.**
