# Task 4 – Configure Azure WAF

## Objective
Create and associate a WAF policy with the Front Door endpoint to inspect incoming web traffic.

## Procedure
1. Create a WAF policy.
2. Configure the required managed security rules.
3. Associate the WAF policy with the Front Door security configuration.
4. Verify the policy is active.
5. Generate a controlled test request suitable for the team's security lab procedure.
6. Check the WAF logs/security events.
7. Review any false positives and tune rules carefully.

## Expected Result
The WAF policy is associated with Front Door and can identify/block applicable malicious requests.

## Safety Note
Use only controlled, authorized test requests against your own project environment. Do not test third-party systems.
