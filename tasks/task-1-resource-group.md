# Task 1 – Create Azure Resource Group

## Objective
Create a dedicated Azure Resource Group to organize the resources required for the public portal.

## Procedure
1. Sign in to Azure Portal.
2. Open **Resource groups**.
3. Select **Create**.
4. Select the required subscription.
5. Enter a project resource-group name.
6. Select the required Azure region.
7. Review and create the resource group.
8. Open the resource group and verify that it is available.

## Expected Result
The project Resource Group is created successfully and is ready to contain the portal, Front Door, WAF, and related resources.
