# Task 2 – Deploy the Public Portal

## Objective
Deploy the public portal using Azure Storage static website or Azure App Service.

## Recommended Demo Portal
The repository includes a static portal in `portal/`.

## Procedure
1. Deploy the files from `portal/` to the selected hosting service.
2. Verify that the hosting service is running.
3. Open the generated public endpoint.
4. Confirm that the page loads correctly.
5. Confirm that CSS and JavaScript resources load.

## Expected Result
The public portal is accessible through the hosting service and can be used as the origin for Azure Front Door.
