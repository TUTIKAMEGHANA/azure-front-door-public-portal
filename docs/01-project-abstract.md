# 1. Project Abstract

The **Azure Front Door with Caching and WAF for a Public Portal** project is designed to provide a fast, secure, and reliable way of delivering a public web portal to users across different geographical locations.

Azure Front Door provides global content delivery by routing user requests through Microsoft's edge locations. Caching improves performance by storing frequently requested content closer to users, while the Web Application Firewall (WAF) protects the application from common web-based attacks.

The project focuses on configuring Azure Front Door, edge caching, WAF policies, HTTPS, and a custom domain. It also addresses common implementation challenges such as stale cached content, WAF false positives, and multi-step domain and certificate configuration.

The proposed solution improves website performance, reduces the load on the origin server, and provides an additional security layer.
