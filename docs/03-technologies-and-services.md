# 3. Services / Technologies Required

| Technology / Service | Purpose |
|---|---|
| Microsoft Azure | Cloud infrastructure |
| Azure Front Door | Global content delivery |
| Azure WAF | Web application protection |
| Azure Storage / App Service | Hosting the portal |
| HTTPS/TLS | Secure communication |
| Custom Domain | User-friendly website address |
| Azure Portal | Resource configuration and monitoring |

- WAF policy
- Custom domain
